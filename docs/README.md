## Status

The repository demonstrates a Dockerized .NET 6 and Angular 16 development/debugging environment. The backend is the standard WeatherForecast API and the frontend is an Angular starter. No e-commerce domain is implemented.

Retain it only as a Docker/IDE-debugging reference until an owner chooses to archive or make it private; it is not a portfolio showcase.
