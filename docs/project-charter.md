# Project charter

## Purpose

Explore local full-stack developer experience with ASP.NET Core, Angular, Docker Compose, hot reload, Dev Containers, and VS Code debugging.

## Verified current scope

- .NET 6 Web API template with WeatherForecast endpoint and Swagger.
- Angular 16 starter application.
- Dockerfiles, Compose variants, proxy configuration, hot reload, and debugger guidance.
- Existing setup documentation for local containers and VS Code.

## Not implemented

- E-commerce products, cart, order, payment, account, inventory, or checkout behavior.
- Domain persistence, an integrated user experience, tests beyond starter assets, CI, and deployment operations.

## Portfolio decision

Classify as a learning/archive candidate. Consolidate its Docker debugging lessons into stronger .NET/Angular projects instead of featuring it separately.
